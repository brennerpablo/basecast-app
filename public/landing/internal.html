Ops

Observability

  • One run log per pipeline run: status, duration, events
  • An Ops screen with service health, pipelines, requests and logs
  • Every API answer carries its as-of date and caveats

Scalability

  • One thin DAG per source, built by a factory
  • Large series in BigQuery, partitioned by month
  • Marts held in memory; the API scales on Cloud Run

Resilience

  • Raw files immutable, with sha256 manifests
  • Idempotent writes: a rerun never duplicates
  • A failed golden check keeps the last good mart live
